# AI-Content Detection Exposé

This repository contains the official exposé for the PhD project titled:

**"Multimodal Detection and Analysis of AI-Generated Content"**

## 🎯 Objective

To develop a robust and interpretable detection system that distinguishes between human- and AI-generated content across **text** and **images**, using advanced **Natural Language Processing**, **Computer Vision**, and **Explainable AI** techniques.

## 📚 Contents

- `Expose.pdf`: The full exposé (poster-ready and approved version)
- `Poster.pdf`: Scientific poster version summarizing the project visually

## 📌 Highlights

- Large-scale dataset (5M+ samples)
- Parallel pipelines for text and image analysis
- Use of SHAP and Grad-CAM for explainability
- Applications in education, media, and scientific publishing
